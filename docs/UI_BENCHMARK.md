# UI benchmark notes — FrameShift v9

Reviewed on 27 October 2026 against publicly advertised patterns in CAT preparation platforms. This notes interaction conventions, not a reproduction of proprietary designs.

- **Question-first practice:** Show the question and options without forcing reflection choices before the attempt.
- **Immediate, specific feedback:** Explain the decisive reasoning steps and, where useful, why distractors fail.
- **Mock analysis and next steps:** Time, accuracy, difficulty and recommended revision are commonly advertised category conventions (for example CATin and IMS), not unique features.
- **Progressive hints:** Begin with a nudge and expose more explicit guidance only when requested.
- **Difficulty selection:** FrameShift's Low / Medium / High selector changes the included question banks. These labels are internally designed and not calibrated against official CAT difficulty.
- **Visual DI:** The data chart includes an SVG label and a table with the same values, so users are not forced to rely only on bar colours/heights.
- **Personalised recap:** The end modal uses a transparent ruleset to recommend a next step based on this session. It is not a validated diagnosis.
- **Calculator and Coach:** These are local utilities; the Coach is a rule-based demo, not a live AI or human tutor.
- **Accessibility:** Use visible focus states, native keyboard controls, readable contrast, reduced-motion support, and mobile layouts. Automated tests do not replace assistive-technology testing.
- **Privacy:** Keep raw surveys, participant notes and exports outside source control. Disclose that session answers remain in the browser unless exported.

## Differentiation boundary

The hypothesis is the curated focus-switch sequence and the later differently framed transfer task—not any individual interface element. Real-aspirant tests are needed to determine whether this design provides incremental learning value.
