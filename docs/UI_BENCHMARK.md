# UI benchmark notes

These are general interaction patterns observed or advertised by CAT preparation tools; the document does not reproduce another product's proprietary interface.

- **Question-first practice:** Keep the prompt and options visible without forcing reflective choices before the student can begin.
- **Immediate, specific feedback:** Explain the decisive step, then optionally expose why distractors fail.
- **Mock analysis:** Time, accuracy and next-step suggestions are common category conventions, not unique features.
- **Progressive hints:** Start with a prompt that preserves the learner's reasoning task; reveal more only if requested.
- **Practice continuity:** Preserve a short, clear journey and avoid forced idle periods.
- **Accessibility:** Use visible focus states, keyboard-native controls, readable contrast, reduced-motion support and an appropriate mobile layout.
- **Privacy:** Do not publish raw user exports. Explain which data stays local and what is included when a user exports a file.

FrameShift's distinctive hypothesis is the *curated sequence* of focus-switch practice and a later transfer task, not any single interface control.
